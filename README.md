El trabajo de prácticas.

Para usar esta mierda:
```
npm create vite@latest
```


Seleccionan:
```
React, Javascript (solo), ESLint, No
```


Luego:
```
npm install tailwindcss @tailwindcss/vite
```


Y finalmente, cada vez que quieran ejecutar la mierda esta:
```
npm run dev
```


asegurense que el programa se siga corriendo en la terminal para que puedan acceder a la página de pruebas (que deberia ser localhost:5173 o localhost:5174, o en el peor de los casos localhost:5175)
